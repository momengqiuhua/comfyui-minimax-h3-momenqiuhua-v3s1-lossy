# 末梦秋花v3s1 · 有损跳步加速

**给 MiniMax H3 视频生成模型用的 ComfyUI 节点。有损加速，20步标准链专用。**

> ⚠️ **这是有损节点**：通过跳过部分采样步来提速，会损失轻微画质。4步蒸馏链上不要用。

---

## 干什么

20步标准链上，判断哪些步可以跳过不算，直接复用上一步结果。15步可缓存，提速约 30-40%。

**什么时候用**：
- 20步标准链（不是4步蒸馏链）
- 追求极限速度，可以接受轻微画质损失
- 批量出片，不在乎单帧完美

**什么时候别用**：
- 4步蒸馏 LoRA 链 —— 4步里只有1步可跳，省的时间不值人脸崩的风险
- 人物特写 / 细节要求高的镜头

---

## 安装

```
下载本仓库 → 解压到 ComfyUI/custom_nodes/ → 重启 ComfyUI
```

搜"顺风飘"找到节点。

## 接线

```
UNET → v4t(等风来) → v3s1(顺风飘) → KSampler(20步)
```

- v4t 选最快 kernel（无损提速）
- v3s1 跳步缓存（有损提速）
- 两个正交叠加，速度最快

---

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| total_steps | 20 | 跟采样器步数对齐 |
| warmup_steps | 3 | 前3步全算，定型 |
| end_protect_steps | 2 | 最后2步全算，保护细节 |
| yang_thresh | 0.15 | 跳步阈值，越小跳越多 |
| adaptive | true | 自适应阈值，前期探索后期保守 |
| shape_protection | true | 形状变化自动重置 |

**大部分默认值不用动，只改 total_steps 跟采样器对齐。**

## 常见问题

**Q: 为什么4步链上不能用？**
A: 4步里只有1步可跳，省的时间约等于零，但人物可能崩。

**Q: 跳步后人脸变了？**
A: 把 yang_thresh 调小（比如0.1），跳得保守一点。或者 end_protect_steps 调到3。

**Q: 跟 v4t 冲突吗？**
A: 不冲突，正交叠加。v4t 选最快 kernel，v3s1 跳步。
